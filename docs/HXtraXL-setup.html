HX Stomp XL · Line 6 3.80.0

Build HXtraXL

Generate the 1.0 firmware with six snapshots, two-slot NAM A2 Lite, and the original Line 6 model names. The build runs in your browser. Your firmware file stays on this device.

Select the original firmware

Use the unmodified HX Stomp XL 3.80.0 .hxf from Line 6. HX Stomp and HX Effects firmware, other versions, and modified files are rejected.

Download HXtraXL 1.0

Before installing

Back up your presets and keep the original Line 6 HXF for recovery. This page creates a file. Installation is a separate step through Line 6 Updater.

HX Edit’s .hlx exports preserve snapshots 1–4. Use a raw USB preset capture when you need to preserve all six.
